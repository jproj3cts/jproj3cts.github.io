JEKray Validation

Each case below takes a published result or an independent code, rebuilds the same setup on a JEKray bench, and compares the numbers. Nothing here is a stored screenshot: the cases run live in your browser, against the version of JEKray the site is serving now, when you open this page.

  • Tolerances were set before the first run, from what the reference itself can claim, and are not adjusted to pass.
  • Where a reference leaves something out, the assumption is written in the case.
  • A failure stays on this page until the model is fixed, or it is recorded as a limit of the model.
  • JEKray works in the plane of the bench. Cases are chosen to be planar or rotationally symmetric.

Each case links to its bench, which opens in JEKray.
