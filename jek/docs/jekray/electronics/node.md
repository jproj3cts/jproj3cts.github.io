<p class="dx-lead">A node is a point on the wiring: one wire in, as many out as you like. It routes wires round a busy bench and fans a signal out to several inputs.</p>

## Ports

One point, both its input and its output: wire an output into it, then drag as many wires out of its centre as you need.

## The model

It hands on what reaches it, unchanged: the same DC, tones and noise on every wire out of it. Any output can already feed several inputs, so a node changes nothing in the solution; it only tidies the drawing.

On the bench it is a small dot, with its name shown only when it is selected. Drag its ring to move it.

## Settings

A node has no settings.
